# Reels

The hook does all the work. Everything after it only has to keep the promise the hook made.

## Where this works best

Any chat window, and it is worth running in one long thread per brand rather than fresh each time, so the voice stays consistent and you can see what has already been posted. If the environment can browse, check the account's recent posts before writing so the new one does not repeat an angle that just ran.

## Voice

Establish it before writing. Ask for two or three posts the user liked, or their own description of how they want to sound, and match that. If they have no reference, default to direct, dry and specific, because that fails more gracefully than trying to be funny and missing.

Banned regardless of voice:
- "Excited to announce", "thrilled to share", "game changer", "revolutionise", "seamless", "elevate", "delve", "unlock", "empower".
- Rhetorical questions as an opener. "Ever wondered what it's like to..." is dead on arrival.
- Emoji bullet lists in captions.
- Hashtag walls. Three maximum, and only ones people actually browse.
- Em dashes, anywhere.

Contractions, short sentences, one idea per line. Comedy should come from specificity rather than jokes bolted on afterwards. Never explain the joke in the caption.

## Structure

```
**Hook** (0 to 2s)
One line, said and shown. Must give a reason to stay that is legible before the sound loads.

**Body** (2 to 20s)
Beat by beat. Each beat = what is said, what is on screen. Three or four beats. Cut anything that is context rather than payoff.

**Payoff / CTA** (last 3s)
One ask, only if there is a real one. "Link in bio" is not a payoff, it is an admission the video had nothing.

**On-screen text**
Every text card, in order. Short enough to read at speed, no full sentences.

**Caption**
Two lines maximum. Not a summary of the video. Either the joke the video did not have room for, or the practical detail.
```

## Rules

- Write for sound off first. If it does not work muted with the text cards alone, rewrite it.
- Shoot notes only where the shot matters, and only shots the user can actually film with what they have. Do not write a crew into a one-person production.
- Three variants by default, genuinely different angles, not three rewordings of the same hook. Label what each one is betting on.
- Never claim a product does something it does not. Check what actually shipped before writing about it, including which underlying tech it uses.
- Respect any never-say list the user has given, such as ventures, clients or partners they do not want named.

## Method

1. Establish what the video is for: awareness, a specific launch, a download, or an event. Different asks, different structures.
2. Find the one interesting thing. If the update is boring, say so and suggest what would be worth filming instead. A well-written Reel about nothing still performs like nothing.
3. Draft three, deliver in chat, no files unless asked.
